🎯 What is OrbitIQ? (The One-Liner)

OrbitIQ is an AI-powered mission health dashboard that pulls live NASA satellite telemetry, automatically detects anomalies using machine learning, and explains what's wrong — in plain English — using IBM Granite.

Think of it as a "check engine light" for spacecraft — but instead of a vague warning, it tells you exactly what the reading means and what the mission risk is.

🚨 The Problem It Solves

Space missions generate thousands of sensor readings every minute. Today, engineers either:

  • Watch dashboards manually — slow, exhausting, error-prone
  • Use rigid threshold rules — miss subtle compound anomalies
  • Receive raw data dumps — with no plain-English explanation of risk

Historical failures like Mars Climate Orbiter and Challenger trace back to missed signals in data that was available but not acted on in time. OrbitIQ addresses this gap directly.

🏗️ How It Works — Architecture

🔧 Component Breakdown

ComponentFileWhat it doesTech
Data Loader orbitiq/data_loader.py Fetches live solar wind plasma + magnetic field from NOAA RTSW API. Merges two streams on timestamps. Returns a clean DataFrame. requests, pandas
Anomaly Detector orbitiq/anomaly_detector.py Trains an Isolation Forest on the live data itself. Scores every reading from 0 (normal) to 1 (highly anomalous). Flags readings above a configurable threshold. scikit-learn, numpy
Granite Client orbitiq/granite_client.py Sends anomaly stats or operator questions to IBM Granite. Returns plain-English explanations. Has retry logic for rate limits. ibm-watsonx-ai, IBM Granite
Charts app/components/charts.py Reusable Plotly helpers: time_series_chart() for trend lines, anomaly_score_chart() for the red/blue scatter with threshold line. Plotly
Dashboard app/streamlit_app.py + pages/ 4-page Streamlit app. Live metrics, interactive charts, anomaly table, and the NL Q&A interface. Streamlit
Tests tests/test_anomaly_detector.py 6 unit tests validating score ranges, predict types, error handling, and threshold sensitivity. All passing. pytest

🎬 3-Minute Demo Script

Use this structure for your video recording or live presentation. Each step maps to one screenshot you already have.

1

Home Page — Set the Scene (30 sec)

Show the home page. Point to the 4 status metrics at the bottom.

"This is OrbitIQ — a mission health intelligence platform. It's pulling live NASA satellite data right now, running machine learning anomaly detection, and using IBM Granite to explain what it finds in plain English. You can see the data source is live, the model is ready, and the AI engine is connected to watsonx."
2

Mission Overview — Show Real Data (40 sec)

Navigate to Mission Overview. Point to the 4 metric tiles, then scroll through the 3 charts.

"We're looking at 3,700+ real readings from NASA's DSCOVR satellite — solar wind speed, proton density, and the IMF Bz magnetic field component. Notice those sharp spikes in the Bz chart — those negative dips are exactly the kind of event that can trigger geomagnetic storms and disrupt spacecraft systems. 3

Anomaly Alerts — The ML Detection (60 sec)

Navigate to Anomaly Alerts. Point to the 3 summary metrics, the scatter chart, then the table.

"Out of 3,718 telemetry records, our Isolation Forest model flagged 48 anomalies — that's about 1.3% of the data. The scatter chart shows normal readings in blue and anomalous events in red. The table lists each one ranked by anomaly score. Now watch this — I'll click 'Explain top anomaly with IBM Granite'..."

→ Click the button. Wait for Granite response. Read it aloud.

"IBM Granite just read those raw numbers and produced a human-readable mission impact statement. That's the core of what OrbitIQ does — it bridges the gap between raw sensor data and actionable insight."
4

Ask OrbitIQ — Natural Language Q&A (40 sec)

Navigate to NL Query. Expand the context panel briefly. Type a question and submit.

"Finally — Ask OrbitIQ. Instead of reading charts, a mission engineer can just ask a question in plain English. I'll ask: 'Is there any geomagnetic storm risk in the next few hours?' — IBM Granite reads the live telemetry context and answers directly. No SQL, no chart-reading required. This is what 'insight-driven' space exploration looks like."
5

Wrap Up (10 sec)

"OrbitIQ was built entirely with IBM Bob as the primary development tool — from architecture design and code generation to debugging and documentation. The full source code is on GitHub. Thank you."
